# Partner logo sources

Partner artwork from first-party project websites and files supplied by the site owner for the partner ticker.

- Aptos: https://aptosnetwork.com/media-kit — original inline header logo; SVG viewport added for standalone scaling.
- Decibel: https://decibel.trade/logo-wordmark.svg — original wordmark asset.
- Sahara AI: https://saharaai.com/ — header asset https://framerusercontent.com/images/QpHZ5AEzH1KLsUmJHp6Q0gp3M9U.svg.
- Bio Protocol: https://www.bio.xyz/ — original inline header logo; standalone CSS variable resolved to the site's #e5ffd1 brand color.

Logo paths and proportions preserved. CSS displays the logos in monochrome for legibility on the pale ticker background.

- Noctra: original PNG from https://noctra.ai/_next/static/media/img-logo-text-primary.037cb203.png, matching the image supplied by the site owner. Stored unchanged as `dist/assets/partners/noctra.png`; no vector tracing or color filter.
